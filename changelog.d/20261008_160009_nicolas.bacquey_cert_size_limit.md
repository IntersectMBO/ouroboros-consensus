### Breaking

- Peras certificate forging can now return `PerasCertTooLargeError` instead of producing a certificate estimated to exceed the configured size limit.

- `snapshotPartition` was replaced by `snapshotPartitionWithInitialPayload`, which takes an additional argument.

- `BlockSupportsPeras` now requires `TxLimits blk` and `IsTxSizeable (TxMeasurePhase1 blk) (PerasCert blk)` constraints.

- Transaction selection (`getTransactionsToForge`) can now reserve room for an optional Peras certificate to be included in the same block body.

### Non-Breaking

- Added `IsTxSizeable` type class to measure arbitrary objects as if they were transactions.

- Added `PerasCertSize` type alias, with a Dijkstra default of 40,000 bytes.

- Added `perasCertSizeUpperBound` to compute a tight size upper bound for `V1.PerasCert` without serialising them.

- Added `splitAfterTxSizeWithInitSize` and `splitAfterTxSizeWithInitSizeOn`, which supersede `splitAfterTxSize` and `splitAfterTxSizeOn`, respectively.
