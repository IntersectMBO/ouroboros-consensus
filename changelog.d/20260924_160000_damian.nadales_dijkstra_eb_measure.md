### Non-Breaking

- Added `Ouroboros.Consensus.Leios.EndorserBlock`, with the types `EndorserBlock` and `TxHash`, and the class `EndorserBlockFormat`.
  The class holds, for each era, the endorser-block encoder `encodeEndorserBlock` and the sizes the mempool charges for it: `encodedReferenceSize` and `encodedMaxFramingSize`.
  `DijkstraEra` has the only instance.
