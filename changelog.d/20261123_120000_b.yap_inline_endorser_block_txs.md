### Non-Breaking

- New `BlockSupportsLeios` method `inlineEndorserBlockTxs`. It puts the transactions of an endorser block into the body of the block that certifies it, the form node-to-client ChainSync will send.
  The header stays the same, so its body hash doesn't match the body.
  By default it returns `Left`, which suits block types that have no endorser blocks. The hard fork combinator passes the call to the block's era.
