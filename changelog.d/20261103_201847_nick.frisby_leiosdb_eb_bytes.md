### Breaking

- `TraceLeiosFetchServerBlockServed`'s `Int` is now the size in bytes of the
  endorser block served, rather than how many transactions it references. The
  `tracing` library renders it as `bytes` rather than `txCount`.
- `LeiosDbReader`'s `lookupEbBody` returns the original encoding of the
  endorser block body written to the LeiosDB, as `Maybe ByteString`, rather
  than the body's transaction references. Its `ebs` table gains an `ebBytes`
  column for it, so LeiosDB files written before must be deleted.

### Non-Breaking

- The LeiosFetch server sends an endorser block in the bytes it was received
  in, rather than in this node's encoding of its transaction references.
- `Ouroboros.Consensus.Leios.Types` gains `endorserBlockBytes`,
  `endorserBlockShortBytes`, `deserialiseEndorserBlock`, and
  `TemporaryEndorserBlockOnlyForEncode` with `temporaryEndorserBlockFromBytes`
  and `unsafeEndorserBlockForEncodeOnly`.
