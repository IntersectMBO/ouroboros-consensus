### Non-Breaking

- Add `mkHotKeyAtEvolutionWithPersist` to
  `Ouroboros.Consensus.Protocol.Ledger.HotKey`: `mkHotKeyAtEvolution` with an
  optional `KESPersistCallback`. After every `evolve` that advanced the key,
  the evolved key is serialised into a fresh locked buffer while the hot key's
  lock is held, and the callback is invoked with the key's absolute period and
  that buffer once the lock has been released. Nothing is invoked for an
  `evolve` that did not change the key. A `PraosCredentialsFile` with a
  `KESPersistHook` now builds its hot key this way, so the node can persist
  the evolved key back to its file.
