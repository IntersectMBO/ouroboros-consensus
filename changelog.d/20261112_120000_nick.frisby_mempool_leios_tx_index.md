### Breaking

- `LedgerSupportsMempool` has three new methods. `txLeiosHash` is the hash
  by which an endorser block references a transaction, and `txLeiosBytes`
  its bytes as Leios sends and stores them. A block type without endorser
  blocks uses `nothingTxLeiosHash` and `nothingTxLeiosBytes`.
  `tickedLedgerMajorProtocolVersion` is the major protocol version under
  which a ticked ledger state validates transactions. A block type whose
  ledger never changes its protocol version gives that version to
  `fixedTickedLedgerMajorProtocolVersion`.
- The `Mempool` has `getLeiosTxIndex`: its transactions that an endorser
  block can reference, by the hash it references them by, and the major
  protocol version they were all validated under, as a `LeiosMempoolTxs`
  from `Ouroboros.Consensus.Leios.Types`.
- `eraTxLeiosBytes` and `eraTxLeiosHash` from
  `Ouroboros.Consensus.Shelley.Eras` replace `serializeTxForLeios` from
  `Ouroboros.Consensus.Shelley.Ledger.Forge`. `LeiosEraDict` requires
  `HashAnnotated (Tx TopTx era) EraIndependentTx` besides
  `SafeToHash (Tx TopTx era)`.
