### Breaking

- `LedgerSupportsMempool` has two new methods. `txLeiosBytes` gives a
  transaction's bytes as Leios sends and stores them, by whose hash an
  endorser block references it. A block type without endorser blocks uses
  `nothingTxLeiosBytes`. `tickedLedgerMajorProtocolVersionWord16` is
  the major protocol version, as a `VersionWord16`, under which a ticked
  ledger state validates transactions. A block type whose ledger never
  changes its protocol version gives that version to
  `fixedTickedLedgerMajorProtocolVersionWord16`.
- The `Mempool` has `getLeiosTxs`: its transactions with the given hashes
  that an endorser block can reference, by the hash it references them by,
  and the major protocol version they were all validated under, as a
  `LeiosMempoolTxs` from `Ouroboros.Consensus.Leios.Types`.
- `serializeTxForLeios` from `Ouroboros.Consensus.Shelley.Ledger.Forge` is gone:
  a transaction's Leios bytes are its `originalBytes`.
