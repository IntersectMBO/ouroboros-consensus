### Breaking

- `LedgerSupportsMempool` has two new methods. `leiosTxMempoolView` gives a
  `LeiosTxMempoolView`, what Leios needs to know about a transaction: the
  hash by which an endorser block references it, and its bytes
  (`leiosTxMempoolViewBytes`). A block type without endorser blocks uses
  `nothingLeiosTxMempoolView`. `tickedLedgerMajorProtocolVersionWord16` is
  the major protocol version, as a `VersionWord16`, under which a ticked
  ledger state validates transactions. A block type whose ledger never
  changes its protocol version gives that version to
  `fixedTickedLedgerMajorProtocolVersionWord16`.
- The `Mempool` has `getLeiosTxIndex`: the `LeiosTxMempoolView`s of its
  transactions that an endorser block can reference, by the hash it
  references them by, and the major protocol version they were all validated
  under, as a `LeiosMempoolTxs` from `Ouroboros.Consensus.Leios.Types`.
- The new class `LeiosEraTx` gives the `LeiosTxMempoolView` of an era's
  transactions (`leiosEraTxMempoolView`), which replaces `serializeTxForLeios`
  from `Ouroboros.Consensus.Shelley.Ledger.Forge`. `LeiosEraDict` requires it,
  instead of `SafeToHash (Tx TopTx era)`.

### Non-Breaking

- New `Ouroboros.Consensus.Util.Unthunkable`: the input from which a record
  computes some of its values afresh every time they are used, so that no
  compiler optimization can share them between uses.
