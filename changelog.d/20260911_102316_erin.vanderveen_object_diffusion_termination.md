### Breaking

- Add an idle timeout argument to `objectDiffusionOutbound` and replace its
  `MonadSTM` constraint with `MonadTimer`.

### Patch

- Apply Peras-specific message byte limits to certificate and vote diffusion,
  including object ID requests and replies, batched objects, and CBOR framing.

### Non-Breaking

- Support the Object Diffusion `MsgServerIdle` message. Return agency after a
  bounded wait so the client can terminate gracefully.
- Add `byteLimitsPerasCertDiffusion` and `byteLimitsPerasVoteDiffusion`,
  using the shared network size budgets and the same batch bounds as the Object
  Diffusion clients.
