### Breaking

- The LeiosDB stores each endorser block point's body and transactions on its
  own, even when another point names the same endorser block, and
  garbage-collects each point on its own. `LeiosDbReader`'s `lookupEbBody`
  takes a `LeiosPoint` rather than an `EndorserBlockHash`, and a `TxLocation`
  names a point. The schema keys bodies and transaction bytes by point, so
  LeiosDB files written before must be deleted.
