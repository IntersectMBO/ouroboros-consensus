### Breaking

- `storeForgedEb` is removed. The node kernel relays the announcement of each
  endorser block it forges, and queues the endorser block, with the header
  announcing it, for a worker thread that hands them to LeiosFetch
  (`onForgedLeiosEb`), so the forge waits on neither LeiosFetch nor the
  LeiosDB. LeiosFetch takes the endorser block in as it would from a peer: it
  takes it into the LeiosTxCache and writes it with its transactions, in one
  write, and once the write lands, records its transactions in the
  LeiosTxCache as validated, holds it with no job left and emits `AcquiredEb`
  and `AcquiredEbTxs`, so the node offers it.
- `ForgedEndorserBlock` carries the major protocol version its transactions
  were validated under (`forgedEbTxsProtVer`), which `forgeLeiosEb` takes.
- The function `forge` calls with a forged endorser block also takes the
  Leios part of the ledger view at the block's slot.

### Non-Breaking

- `Ouroboros.Consensus.MiniProtocol.LeiosFetch.Decision` gains
  `holdForgedEb`: once the write of an endorser block the node's own forge
  produced lands, it holds that block with no job left, whatever its point was
  in, and returns the acquisitions not yet emitted at that point.
- `Ouroboros.Consensus.MiniProtocol.LeiosNotify.Client.Announcements.Validation`
  gains `validHeaderAnnouncement`: the announcement a header carries, once the
  header is known to be valid, as one the node's own forge built is.
