### Breaking

- `storeForgedEb` is removed. Once the forge adopted its ranking block, the
  node kernel relays the announcement of the endorser block it forged and hands
  the endorser block to LeiosFetch (`onForgedLeiosEb`), which takes it in as it
  would from a peer: it writes it, and once both writes are durable holds it
  with no job left and emits `AcquiredEb` and `AcquiredEbTxs`, so the node
  offers it.
- `forge` calls the function it takes for a forged endorser block after
  `addBlockToChainDB` adopted the ranking block, not before, and also passes it
  the Leios part of the ledger view at the block's slot.

### Non-Breaking

- `Ouroboros.Consensus.MiniProtocol.LeiosNotify.Client.Announcements.Validation`
  gains `validHeaderAnnouncement`: the announcement a header carries, once the
  header is known to be valid, as one the node's own forge built is.
