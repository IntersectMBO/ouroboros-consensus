### Breaking

- Every tracer in the public API is now a `Hermod.Tracing.API.Tracer.Tracer`
  (a synonym for hermod's `Trace`) from `hermod-tracing-api`, instead of
  `Control.Tracer.Tracer` from `contra-tracer`. The vocabulary is unchanged --
  `Tracer`, `traceWith`, `nullTracer`, `mkTracer`, `natTracer`, `contramapM`,
  `contramap`/`(>$<)`, `debugTracer`, `stdoutTracer` all keep their signatures,
  constraints and argument order -- so downstream code migrates by replacing
  `import Control.Tracer` with `import Hermod.Tracing.API.Tracer` and the
  `contra-tracer` build dependency with `hermod-tracing-api:public`. A tracer
  that is still passed to an API speaking `contra-tracer` is bridged with
  `Hermod.Tracing.API.ContraTracer.toContraTracer`.
  Affected, among others: `Ouroboros.Consensus.Node.Tracers.Tracers'`,
  `Ouroboros.Consensus.Network.NodeToNode.Tracers'`,
  `Ouroboros.Consensus.Network.NodeToClient.Tracers'`, every `defaultArgs`
  record carrying a tracer, and the `NoThunks (Tracer m ev)` orphan in
  `Ouroboros.Consensus.Util.Orphans`.
  This requires the matching ouroboros-network release, in which `network-mux`,
  `ouroboros-network` and `cardano-diffusion` use `hermod-tracing-api` too.
