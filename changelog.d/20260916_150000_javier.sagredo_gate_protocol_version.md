### Non-Breaking

- db-analyser and db-synthesizer now derive the greatest protocol version they
  work in from the node configuration, through the new
  `Cardano.Tools.Config.mkProtocolVersion`, instead of always announcing the
  latest era they know about.

  This follows cardano-node, which gates it on `ExperimentalHardForksEnabled`:
  with the flag off the version stops at the era before the experimental one.
  Previously the tools announced the experimental era whatever the configuration
  said, so db-synthesizer could forge in an era a node reading the same
  configuration would not.
