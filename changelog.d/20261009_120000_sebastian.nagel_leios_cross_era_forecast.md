### Patch

- A Dijkstra ledger view forecast from a Conway ledger state now carries Dijkstra's Leios parameters and committee. It used to carry placeholder values, such as a maximum endorser block size of 0. A node whose selection was still in Conway then rejected every announcing Dijkstra header (`LeiosEbTooBig`), and disconnected honest peers with `ExnInvalidLeiosAnnouncement`.

- The announcement size check no longer grants the deployed testnet's historical announcements an exception to `maxEndorserBlockReferencesSize`.
