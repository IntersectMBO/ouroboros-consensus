### Breaking

- `PerasBootstrapRound` type is replaced by `PerasBootstrapStatus`, which is either
  `PerasBootstrapDisabled` or `PerasBootstrapEnabled` with a `PerasRoundNo`.
  `perasBootstrapStatusFromMaybe` and `perasBootstrapStatusToMaybe` convert it
  from and to a `Maybe Word64`.
- `PerasParams`'s `perasBootstrapRound` is replaced by `perasBootstrapStatus`.
- Introduced `PerasBootstrapAndRecoveryInteractionOutcome` to encapsulate the interaction between the bootstrap round and the latest certificate on the preferred chain for VR-2B, giving the reference round. VR-2B holds if the
  current round is exactly c⋅K rounds after the reference round, for some
  c ≥ 0, and fails if there is no reference round.
- `VR2B` carries a `PerasBootstrapAndRecoveryInteractionOutcome` for explainability
- A node that has never seen a Peras certificate can no longer vote through VR-1A
  and VR-1B, only through VR-2A (which now holds in that case), and VR-2B.
