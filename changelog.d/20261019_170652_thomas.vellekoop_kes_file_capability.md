### Non-Breaking

- Add the method `withKESKeyFileLocked` to
  `Ouroboros.Consensus.Protocol.Praos.AgentClient.MonadKESAgent`. It reads a
  whole file into a fresh mlocked buffer, runs a continuation on it and erases
  the buffer afterwards, so a KES signing key file can be read without any of
  its contents passing through the GHC heap. The `IO` instance reads the file;
  the `IOSim` instance throws the new `KESKeyFileNotSupportedInSimulation`.
  Instances of `MonadKESAgent` outside this repository need to add the method.
