### Breaking

- Follow `ouroboros-network` `main`, which now carries tx-submission
  configuration per connection.
- `mkNodeKernelArgs` takes the node's `TxSubmissionLogicVersion`, for which it
  builds the default `MiniProtocolParameters` with `ouroboros-network`'s
  `mkDefaultMiniProtocolParameters`.
- `NodeKernel` has a new field, `getTxSubmissionConfig`, which gives a
  connection's `TxSubmissionConfig` for its negotiated `NodeToNodeVersion`.
- `NodeKernel` now builds `getTxDecisionPolicy` from the node's
  `MiniProtocolParameters` with `mkNodeTxDecisionPolicy`. The node halts if the
  tx-submission configuration is invalid.
- `Ouroboros.Consensus.Network.NodeToNode.mkHandlers` and
  `Ouroboros.Consensus.Node.mkNodeToNodeApps` no longer take a
  `TxSubmissionLogicVersion`: the inbound tx-submission logic is the
  `txSubmissionLogicVersion` of the `NodeKernelArgs`' `MiniProtocolParameters`.

### Non-Breaking

- Support `NodeToNodeVersion` `NodeToNodeV_17` for Cardano and Shelley blocks.
