### Breaking

- `newLeiosVoteState` takes a second argument, whether a point is votable, and
  `AddVoteResult` gains `NotVotable`.
- `LeiosVote`'s `voteSignature` is a `LeiosSignatureBytes`, unpacked by
  `validateLeiosVote`, which now also returns the unpacked signature.
  `VoteInvalid` gains `MalformedSignature` and `LeiosNotifyException` gains
  `LeiosNotifyMalformedVote`.

### Non-Breaking

- A node takes votes only for the newest `leiosVoteWindow` blocks of its chain
  (`withinVoteWindow`), checked before validation; any other vote is dropped
  and not relayed. Votes for points the vote state had already evicted were
  counted and relayed again, so a set of old votes could circulate without end.
- A vote's signature is unpacked into a point only when the vote is validated,
  so a dropped vote costs no curve arithmetic, and a relayed one is sent as the
  bytes received. A peer whose signature on a votable point is not a point is
  disconnected.
