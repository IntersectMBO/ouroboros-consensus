### Breaking

- Ledger state snapshots are now written with snapshot encoding version 2, and
  that is the only version the snapshot decoder accepts. Snapshots written by
  earlier versions, including the pre-versioned format, cannot be read and
  have to be regenerated.
- The inner version numbers of the snapshot contents are gone: `PBftState`,
  `TPraosState`, `PraosState`, `LeiosState` and the Shelley ledger state are no
  longer wrapped in `encodeVersion`, as the snapshot version covers all of them.
- The `WithOrigin` tip of the Byron ledger state and the last slot of
  `PraosState` are now encoded with `encodeWithOrigin` (`[]` / `[x]`) like the
  rest of the snapshot, instead of the generic `Serialise` encoding. As
  `DebugChainDepState` uses the same encoding, its result changes too.
- `decodeLBackwardsCompatible` was renamed to `decodeL` and only takes the
  ledger decoder. `readExtLedgerState` no longer takes a header hash decoder.
