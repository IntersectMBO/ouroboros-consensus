### Breaking

- Added `hardForkProjTxMeasurePhase1`, `hardForkProjTxMeasurePhase2` and `hardForkProjTxEbMeasure` to the `CanHardFork` class.
  Projecting the injection of a measure gives back that measure.
  Each one returns a measure at every era position, and the caller picks one era with `projectNP`.
  The methods have no default.
  An instance that does not define them compiles with only a `-Wmissing-methods` warning.
  It fails at run time the first time `hardForkBlockForging` forges a block.
- `Ouroboros.Consensus.Block.Forging.forgeBlock` returns the new `ForgedBlock`, which holds the forged block, the transactions that `forgeBlock` selected for it and their total measure.
  `forgeShelleyBlock`, `forgeByronBlock`, `forgeDualByronBlock` and `forgeSimple` return a `ForgedBlock` too.
- The forge loop traces `forgedTxsMeasure` in `TraceForgedBlock`.
  For a hard fork block it is the era's measure, injected back into the combined measure.
  So for a Cardano block before Dijkstra, the traced endorser-block measure has a zero `txReferencesSize`.
- `ForgeBlockArgs` has `fbMempoolSnapshot` in place of `fbTxs`.
  Each era's `forgeBlock` selects its own transactions from the mempool snapshot.
- `forgeShelleyBlock`, `praosBlockForging`, `praosSharedBlockForging`, `shelleyBlockForging`, `shelleySharedBlockForging`, `leiosSharedBlockForging` and `protocolInfoTPraosShelleyBased` require `TxLimits` for the Shelley-based block.
- `forgeRegularBlock` takes the block config, block number, slot number, ticked ledger state, transactions and leader proof as separate arguments.
- The db-synthesizer's `runForge` requires `LedgerSupportsMempool blk` and `HasTxId (GenTx blk)`.

### Non-Breaking

- `Ouroboros.Consensus.HardFork.Combinator.Mempool` exports `injectValidatedGenTx`.
- `Ouroboros.Consensus.HardFork.Combinator.Forging` exports `projectMempoolSnapshot` and `injectForgedBlock`.
- Added `selectBlockTxs` to `Ouroboros.Consensus.Block.Forging`.
  It gives the ranking-block part of a mempool snapshot and its measure, for a forge that never builds an endorser block.
- Added an `Isomorphic` instance for `MempoolSnapshot` to `Ouroboros.Consensus.HardFork.Combinator.Embed.Unary`.
