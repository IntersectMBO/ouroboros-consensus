### Breaking

- `LeiosDbWriter`'s `writeEbPoint` is removed: `writeEbBody` records its point
  itself, in the same transaction, so neither backend needs the point written
  first. The `ebs` table loses `ebBytesSize`, so LeiosDB files written before
  must be deleted.

### Non-Breaking

- The LeiosDB SQLite write queue is one job shallower: a forged endorser block
  takes two jobs rather than three, since its point is no longer written on
  its own.
