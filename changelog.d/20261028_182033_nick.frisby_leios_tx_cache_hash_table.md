### Non-Breaking

- `Ouroboros.Consensus.Leios.TxCache` gains `newHashTableLeiosTxCache`, a
  LeiosTxCache backed by a mutable, salted, open-addressing hash table, in
  `Ouroboros.Consensus.Leios.TxCache.Optimized`.
- The node shuts down if that hash table ever holds a protocol version its
  ledger cannot represent (`ExnLeiosTxCacheCorruptVersion`), which only a bug
  or memory corruption could cause.
