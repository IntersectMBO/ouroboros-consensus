### Breaking

- The tools now read the node configuration through the shared `cardano-config`
  package, and `db-synthesizer` reads its forging credentials through it too
  (`cardano-config:keys` decodes the key material). The 2022 fork of
  `cardano-api`'s key layer that `unstable-cardano-tools` carried for that
  purpose -- `Cardano.Api.*`, `Cardano.Node.Protocol.*` and `Cardano.Node.Types`,
  some 3,800 lines -- is gone, as is `Cardano.Tools.DBSynthesizer.Orphans`.

  What replaces them in that component is `Cardano.Tools.Config` (what the tools
  derive from a resolved node configuration, plus the `ConfigError` that used to
  live in `Cardano.Tools.DBAnalyser.Types`) and `Cardano.Tools.Credentials` (the
  decoded credentials, as consensus leader credentials).
  `Cardano.Tools.DBSynthesizer.Run` correspondingly lost the configuration types
  it used to hand around: `initialize` takes the configuration file and the
  credentials and returns a ready-made protocol, which `synthesize` forges with.

- `db-synthesizer`'s credential options are now `cardano-node`'s own, taken from
  `cardano-config`: Byron credentials (`--byron-delegation-certificate`,
  `--byron-signing-key`) and a KES agent (`--shelley-kes-agent-socket`) work
  alongside the KES/VRF/operational-certificate files and the bulk credentials
  file it already accepted. A configuration stub is no longer enough, though: the
  configuration file has to be one `cardano-config` accepts.

### Non-Breaking

- `db-synthesizer`'s `-f` and `-a` now do what they say: they were parsed as
  switches inside an alternative, so the first branch always matched and every
  run force-overwrote the ChainDB, whether or not either flag was given.

- `db-analyser` takes the LedgerDB backend from the node configuration file when
  neither `--in-mem` nor `--lsm` is given, and gained `--lsm-export` to export
  snapshots from the LSM backend. Configuration warnings are reported on stderr,
  and every configuration problem is now reported as a plain message rather than
  as a backtrace.
