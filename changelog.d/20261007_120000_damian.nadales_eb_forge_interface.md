### Breaking

- `forgeBlock` returns the forged block and a `Maybe ForgedLeiosEb`: the endorser block that the block announces. Only Dijkstra (`Praos2`) builds an endorser block, and only from a non-empty `fbEbTxs`. Every other era returns `Nothing`.
- `forgeShelleyBlock` returns the forged block and a `Maybe ForgedLeiosEb`, and requires `Foldable (WhenLeios proto)`. If the protocol has Leios and `fbEbTxs` is not empty, the header announces the endorser block that `forgeShelleyBlock` returns.
- `praos2SharedBlockForging` requires `LedgerSupportsProtocol (ShelleyBlock (Praos2 c) era)`. Its `forgeBlock` asserts that the endorser block it returns is not larger than `plvMaxEbBodySize`.
- `ForgeBlockArgs` has a new field, `fbEbTxs`: the transactions for the endorser block. `snapshotPartition` selects them after the ranking-block transactions in `fbTxs`.
- `Ouroboros.Consensus.NodeKernel.Forge.forge` takes a new argument. It calls this argument with each forged endorser block after the ChainDB adopts the ranking block. The node kernel and db-synthesizer pass a function that does nothing.

### Non-Breaking

- New type `ForgedLeiosEb` in `Ouroboros.Consensus.Leios.Types`.
- New functions in `Ouroboros.Consensus.Leios.Types`: `leiosEbFromTxBytes` builds an endorser block from the bytes of its transactions, and `hashLeiosEb` gives the hash that a header announces for an endorser block.
