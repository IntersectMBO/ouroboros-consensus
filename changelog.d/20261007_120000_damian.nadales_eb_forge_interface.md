### Breaking

- `forgeBlock` returns the forged block and a `Maybe ForgedLeiosEb`: the endorser block that the block announces. Every era returns `Nothing`.
- `ForgeBlockArgs` has a new field, `fbEbTxs`: the transactions for the endorser block. `snapshotPartition` selects them after the ranking-block transactions in `fbTxs`.
- `Ouroboros.Consensus.NodeKernel.Forge.forge` takes a new argument. It calls this argument with each forged endorser block after the ChainDB adopts the ranking block. The node kernel and db-synthesizer pass a function that does nothing.

### Non-Breaking

- New type `ForgedLeiosEb` in `Ouroboros.Consensus.Leios.Types`.
