### Breaking

- `maxLeiosEbBytesSize` is 600 kB (600,000 bytes), up from 512 KiB, and is meant to equal the constitution's guardrail on `maxEndorserBlockReferencesSize`. A node refuses to run with the parameter above it, so raising the guardrail needs a node release first.

- `maxTxsPerEb` rises from 14,979 to 17,142, since it derives from `maxLeiosEbBytesSize`. It sizes the LeiosFetch server's per-peer buffers and bounds the bitmaps it accepts, and `worstCaseCacheTxCount` still fits the tx cache's table about twice over.
