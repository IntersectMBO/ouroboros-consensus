### Breaking

- The ChainDB's `addBlockAsync`, `addBlock`, `addBlock_` and
  `addBlockWaitWrittenToDisk` take, if the block contains a Leios
  certificate, what checking it takes (a `CertRbInfo`).
- BlockFetch's matched block is now a `MatchedBlock`, which carries that
  from the header the block matched.
- `InitChainDB`'s `addBlock` is renamed `addTheFirstEbb`.
