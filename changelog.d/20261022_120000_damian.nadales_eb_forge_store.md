### Breaking

- `ShelleyBasedEra` has a new method, `getLeiosEraDict`. It returns what the Leios protocol needs to know about the era. Only Dijkstra supports Leios, so only Dijkstra returns `Just`.
- `ShelleyBasedEra` loses the method `blockBodyLeiosCert` and `defaultBlockBodyLeiosCert`. `blockMatchesHeader` and `blockLeiosCert` read the certificate with `leiosCertBlockBodyL` from `getLeiosEraDict`.
- `serializeTxForLeios` from `Ouroboros.Consensus.Shelley.Ledger.Forge` needs `SafeToHash (Tx TopTx era)`. It uses `toCBORForBlockInclusion`, which keeps the `is_valid` flag.

### Non-Breaking

- If a write to the in-memory LeiosDB fails, `writeEbPoint`, `writeEbBody` and `writeTxs` throw at submission. Thus a caller that does not `await` the `Promise` sees the failure.
- The node kernel writes each forged endorser block to the LeiosDB. The forge does not await the writes. On SQLite, it blocks while the write queue is full. If a write fails, the node stops.
- The depth of the LeiosDB SQLite write queue counts three jobs for the forge: the point, the body and the transactions of a forged endorser block.
- `Ouroboros.Consensus.Storage.LeiosDB.API` exports `storeForgedEb`, which writes a forged endorser block to the LeiosDB. The node kernel gives it to `forge`.
