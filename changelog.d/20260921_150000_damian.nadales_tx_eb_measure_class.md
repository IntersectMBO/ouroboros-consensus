### Breaking

- Added `TxEbMeasure`, `txEbMeasure`, `ebCapacityTxMeasure` and `ebClosureCapacityTxMeasure` to the `TxLimits` class.
  They state the size a transaction takes in a Leios endorser block, and the endorser-block capacity a ledger state allows.
  All four have defaults.
  The endorser-block measure of a transaction is its block measure, and both capacities are zero.
  No block type overrides them, and nothing reads them, so no era changes behaviour.

- Added `HardForkTxEbMeasure`, `hardForkInjTxEbMeasure` and `hardForkTxEbMeasure` to the `CanHardFork` class.
  They let the combinator carry the endorser-block measure across eras.
  They have no defaults, so existing `CanHardFork` instances must supply them.

- Added `WrapTxEbMeasure` to `Ouroboros.Consensus.TypeFamilyWrappers`.
