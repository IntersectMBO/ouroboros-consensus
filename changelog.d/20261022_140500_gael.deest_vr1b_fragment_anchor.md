### Breaking

- Remove `WithBoostedBlockStatus` from the `PerasCertDB` API: `getLatestCertSeen`
  and `ChainDB.getLatestPerasCertSeen` now return the latest certificate seen
  directly.

### Patch

- Fix voting rule VR-1B always failing: the voting view now checks the block
  boosted by slot computation instead of relying on a status flag updated
  by garbage collection.
