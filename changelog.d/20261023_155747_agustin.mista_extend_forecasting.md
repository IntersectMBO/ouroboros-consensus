### Breaking

- Remove `LedgerStateSupportsPeras` and `ChainDepStateSupportsPeras`. Move their responsibilities to `StateSupportsPerasEpochContext`; update instances and constraints that refer to either removed class.

- Expand `StateSupportsPerasEpochContext` with methods to obtain pool distributions from ticked and unticked ledger states, nonces from ticked and unticked header states, and `PerasParams` from ticked and unticked ledger states. Implement these methods for each Peras-capable block type.

- Change `mkBoundedPerasEpochContext` to take epoch-to-round information, `PerasParams`, `PoolDistr`, and `Nonce`, rather than ledger and chain-dependent states. Change `mkBoundedPerasEpochContextWith` and the `mkPerasVotingCommitteeInput` and `mkMockPerasVotingCommitteeInput` helpers to accept a pool distribution, nonce, and target committee size.

- Rename `initPerasEpochContextResolver` to `initPerasEpochContextResolverFromUntickedState`. Update imports and call sites using the old name.

- Change `dijkstraPerasRoundLength` from `PerasEnabled PerasRoundLength` to `PerasRoundLength`. Wrap it with `PerasEnabled` where an enabled value is required.

- Move `maxRollbackWeight` from `Ouroboros.Consensus.Config.SecurityParam` to `Ouroboros.Consensus.Peras.Params`; update imports of this function.

### Non-Breaking

- Add and export `mkPerasParams`, which derives `PerasParams` from the security parameter, active slot coefficient, and `PerasLedgerView`. Dijkstra now derives its Peras parameters from the ledger view rather than using a fixed parameter bundle; the HFC dispatches derivation to the active era.

- Export `dummyPoolDistr` from `Ouroboros.Consensus.Peras.Context` for blocks that do not support Peras and test instances that require a non-empty pool distribution.
