### Breaking

- Add an idle timeout argument to `objectDiffusionOutbound` and replace its
  `MonadSTM` constraint with `MonadTimer`.
- Pass negotiated `PerasSupport` through `aChainSyncClient` and
  `bracketChainSyncClient`, and expose it as `csPerasSupport`.
- Replace `GsmView.getChainSyncStates` with `getPeerStates`.

### Non-Breaking

- Support the Object Diffusion `MsgServerIdle` message. Return agency after a
  bounded wait so the client can terminate gracefully.
- Support the Object Diffusion `MsgAwaitReply` message, making server idleness
  explicit before it waits for new object IDs.
- Include negotiated Peras certificate-diffusion idling in GSM caught-up
  detection. Track certificate-client registration and idling separately from
  ChainSync; exclude vote diffusion from this condition.
- Expose `Ouroboros.Consensus.MiniProtocol.ObjectDiffusion.Inbound.State`,
  `Ouroboros.Consensus.MiniProtocol.Util.Idling`, and
  `Ouroboros.Consensus.Node.GSM.PeerState`.
